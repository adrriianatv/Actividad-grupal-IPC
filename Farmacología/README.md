# Farmacología y reposicionamiento de fármacos

Incluye el screening de fármacos actuales en cuanto a la resistencia de esos antibióticos y búsqueda de nuevos candidatos para reposicionamiento.
A partir de los resulados de RNAseq y del análisis estructural de las proteínas.


## Archivos de la carpeta

* `README.md`: describe el propósito de esta etapa del proyecto
* dianas.txt : listado de las proteínas seleccionadas tras el análisis de expresión
* reposcionamiento.py : scripts base para filtrar y cruzar los fármacos candidatos
* screening.r : evaluación de los candidatos y generación de gráficos 
* candidatos.csv : tabla de referencia para los resultados obtenidos de esta búsqueda incluyendo la diana asociada
* cristerios.md : apuntes sobre los criterios de selección de los fármacos candidatos

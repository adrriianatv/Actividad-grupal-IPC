# Documentación de Buenas Prácticas de Laboratorio

En este directorio hemos incluido varios formatos de archivo de EJEMPLO. Esto quiere decir que los archivos no contienen datos ni códigos reales.

## Archivos de ejemplo

- **`*.csv`**:  ejemplo de base de datos 

- **`.txt`**: documento de texto que incluiría la descripción de las Buenas Prácticas de Laboratorio (en inglés, Good Laboratory Practices o GLP)

- **`.py`**: ejemplo de scripts con código en Python en el que hemos añadido el mítico 'Hola mundo'
